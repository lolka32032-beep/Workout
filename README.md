# Тренировки

Дневник тренировок в одном HTML-файле: подходы и веса, личные рекорды, прогресс, таймер отдыха. Работает офлайн, устанавливается на экран телефона как приложение.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `manifest.webmanifest` | PWA-манифест (название, иконки, standalone) |
| `sw.js` | service worker: офлайн-кэш оболочки |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | иконки приложения |

Ни сборки, ни зависимостей, ни сети — данные хранятся в `localStorage` браузера.

## Возможности

- **Дневник** — тренировки по датам, прогресс недели к цели, серия недель, повтор прошлой тренировки одним тапом.
- **Тренировка** — упражнения из библиотеки, подходы (вес × повторы, повторы, время, дистанция), итоговый объём, таймер отдыха.
- **Упражнения** — 38 упражнений по группам (зал, дом, бег, плавание), рекорды, поиск, свои упражнения.
- **Прогресс** — графики тренировок и тоннажа по неделям, личные рекорды, история по каждому упражнению.
- **Ещё** — настройки отдыха и цели, резервная копия в JSON, восстановление.

## Как открыть

- Локально: открыть `index.html` в браузере.
- На телефоне: открыть опубликованную ссылку GitHub Pages → «Поделиться» → «На экран Домой».

## Публикация на GitHub Pages

1. Создать публичный репозиторий, загрузить в корень все файлы из этой папки.
2. `Settings → Pages → Source: Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту приложение доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

При изменениях файлов нужно поднимать `VERSION` в `sw.js` (и `APP_VERSION` в `index.html`), иначе телефон продолжит показывать старую версию из кэша.

## Данные

Всё лежит только на устройстве. Копия — «Ещё → Сохранить копию (JSON)»; восстановление заменяет данные на телефоне.
